# Security policy

Do not report suspected vulnerabilities through public GitHub issues or post
credentials, personal data, deployment URLs with private access, or exploit
details publicly.

Report vulnerabilities privately to <security@radixracingcollective.com> with:

- a concise description and affected version or commit;
- reproducible steps or a proof of concept where safe to provide;
- the security impact; and
- a contact method for follow-up.

We will acknowledge receipt, investigate, and coordinate a fix and disclosure
timeline with the reporter. The official hosted service has its own production
secrets and access controls; a public source-code report does not authorize
access to it.
